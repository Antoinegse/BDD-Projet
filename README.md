Voici notre projet de base de donnée :

Pour lancer le projet,

Créer tout d'abord la base de données avec la query dans le dossier étape 2
Insérer les informations de la base à partir des query dans le dossier étape 3 et créer les index, vues, etc à partir des autres query se trouvant dans le même dossier.
Changer le mot de passe pour accéder à votre base de donnée dans le fichier DatabaseConfig.java
Finalement, déplacer dans le dossier ArtConnectPro-App puis effectuer la commande mvn clean javafx:run

Elements supplémentaires :
Dossier étape 1 : notre analyse fonctionnelle de l'application
Dossier étape 2 : les diagrammes looping qui montre les relations entre les tables de notre BDD
Dossier étape 3 : résumé des fonctionnalités avancées en sql
